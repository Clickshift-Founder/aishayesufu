# /images — Campaign Image Files

Place all images in this folder. The site references them by exact filename.
Supported formats: .jpg  .jpeg  .png  .webp
Recommended: JPG for photos, PNG for logos/graphics with transparency.

────────────────────────────────────────────────────────────
REQUIRED FILES (site breaks without these)
────────────────────────────────────────────────────────────

aisha-logo.png
  → Campaign logo (PNG with transparent background recommended)
  → Used in navigation bar across all pages
  → Ideal size: 300px wide, any height up to 80px

aisha-hero-bg.jpg
  → Full-screen hero background on the Homepage
  → Should feature Aisha — a strong, powerful image works best
  → Ideal size: 1920 × 1080px minimum. Will be cropped to fill screen.

aisha-portrait-main.jpg
  → Portrait shown beside the campaign video (Homepage, after ticker)
  → Ideal: vertical/portrait orientation, 800 × 1000px minimum
  → Works best if she's facing slightly left (toward the video)

aisha-about-bg.jpg
  → Background image for the About page hero section
  → Can be the same as hero-bg.jpg or a different shot
  → Ideal size: 1920 × 800px

────────────────────────────────────────────────────────────
TIPS
────────────────────────────────────────────────────────────
• Compress images before uploading (use squoosh.app — free)
• File names are case-sensitive — use lowercase exactly as listed
• If an image is missing the site degrades gracefully (fallback color)
• This /images folder lives at the root alongside index.html
